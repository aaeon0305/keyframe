Canvas

Drag, align, and scale anything on stage.

The canvas is the source of truth. Every layer you place is a real DOM element with eight resize handles, grid-aware snapping, and full keyboard nudging. Text, boxes, circles, imported SVGs — they all behave the same way.

  • Six canvas presets and any custom size, up to 4000×4000
  • Adjustable grid from 4px to 120px with snap-to-grid
  • Eight-direction resize handles with optional aspect lock
  • Arrow-key nudging, Shift for 10px steps
  • Auto-scaling mobile viewport that keeps the aspect ratio correct
Motion components

Three building blocks. Infinite combinations.

Every layer in the studio can carry three kinds of motion components. They stack in parallel, they never fight, and they all compile into a single GSAP timeline when the scene is built.

  • Base — Fade, Up, Down, Left, Right, Scale, Rotate, Blur, Skew
  • SplitText — Reveal text by character, word, or line with stagger control
  • Motion Path — Click points on the canvas to draw a curve the layer travels along

Timeline

A nested timeline that shows every component.

The footer is the entire scene, laid out as a nested object timeline. Each layer gets a group bar that shows its total span, and each animation component inside the layer gets its own sub-bar. Drag anything to adjust delay or duration.

  • Group bar per layer, sub-bar per component
  • Drag the bar to change delay, drag the right edge to change duration
  • Editable total duration — the timeline pads itself automatically
  • Scrub anywhere in the timeline to preview the state at any moment
  • Speed multiplier from 0.1× to 3×, applied globally

Vector editing

Real vector editing, directly on the canvas.

Import any SVG and every sub-shape becomes an editable object with anchors you can drag. The Mesh Mode lets you reshape paths, circles, and rectangles without ever touching a code editor.

  • Press M to enter Mesh Mode on any layer with sub-shapes
  • Click any shape to isolate it, then drag its anchors to reshape
  • Full shape list with per-shape property editing
  • Vector scale panel — uniform scale, lock aspect, quick size chips
  • Icons default-size slider that sets the size for every new icon
Easing

58 ease presets and a draggable Bézier editor.

Every animation component uses an ease, and Keyframe gives you an exhaustive library from day one — plus a live editor for building your own curve when the presets aren't enough.

  • Five Keyframe families: enter, exit, emphasis, path, settle
  • All GSAP easings: Power, Expo, Circ, Sine, Back, Elastic, Bounce
  • Two-dropdown picker — pick a category, then pick a preset
  • Live preview dot that rides the curve as you browse
  • Custom Mode with two draggable control handles
Export

Copy-paste code that runs anywhere.

Every scene you build compiles into code. The export panel is not a screenshot — it's the scene, serialized. Copy the output, drop it into any page, and it plays identically.

  • Standalone HTML — a complete single-file page
  • React JSX / TSX — a component with forwarded ref
  • Framer — a code component with property controls
  • Inline Script — a drop-in snippet for any existing page
  • Fonts load with the exact weights you configured — static families work

07Elements

The visual vocabulary of the system.

Four recurring visual motifs that carry the brand across every surface. Use them in covers, thumbnails, social posts, and title cards.

Diamond grid

Repeating diamonds in the five motion family colors. Used as background texture on dark surfaces.

Motion trail

Descending opacity blocks that imply direction and speed. Used for loading states and transitions.

Motion path

A dashed curve connecting colored control points. Used to imply sequence and travel.

Timeline bars

Rounded rectangles at descending opacity. Used in headers, hero images, and promotional graphics.

Every element describes a specific kind of motion. Nothing is decorative.
