Keyframe Motion Studio — v2.5

    
Rotation now persists across timeline rebuilds. Motion paths stay independent.

    
What's new in v2.5

    
    
      
  • Rotation fix. Rotation lives on a dedicated .el-rot layer that GSAP never touches, so it survives every buildTimeline() cycle.
    • 
      
  • Motion path independence preserved. Path transforms still target .el-path; rotation lives deeper on .el-rot. Rotating an object no longer bends its motion path.
    • 
      
  • Export is canvas-accurate. Uses flex centering so the scene renders at full size in any browser.
    •
